# Modern UI Guide

Open `modern-preview/index.html` directly in a browser. The modern light-theme demo has six local illustrative event images under `modern-preview/assets/images/events/`. It is separate from the original PHP/MySQL application under `templates/` and `php/`. Event search, filtering, detail screens and demo forms work in the browser. Authentication, real bookings, event publishing, payments and persistent storage are **not** connected to the preview.

The event photographs are cropped from an AI-generated design concept, not documentation of real events.
